# Road Safety Data Visualisation

Interactive D3.js dashboard comparing road-related hospitalisation rates across 
Australian remoteness areas and Indigenous status.

## Overview

Combines a linked time-series and bar chart to compare crash hospitalisation 
rates over time and by region, using per-100,000-population rates so areas of 
different sizes can be fairly compared.

## Data

Five datasets from BITRE and ABS (2011–2021), covering national, state, and 
First Nations hospitalised injuries by remoteness area.

## Design Process

Explored in KNIME before building in D3 — see `knime/road-safety-exploration.knwf`. 
An early pie chart was dropped after usability testing in favour of the bar chart.

## Built With
